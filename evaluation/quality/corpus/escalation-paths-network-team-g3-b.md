# Network Team change freeze rules

Restricted to the Network Team. Not for general distribution.

## Freeze windows
The network change freeze runs from 15 December to 5 January, and during any SEV1.

## During a freeze
Only a change that restores a failed service is permitted. A change that improves
resilience is deferred.

## Exception
A freeze exception needs the duty network manager and the change manager together.

## Recording
Every freeze exception is recorded in the network change log with its justification.
