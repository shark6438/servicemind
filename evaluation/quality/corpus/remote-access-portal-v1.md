# Remote access portal enrolment (version 1)

This version has been withdrawn. It is retained for reference only.

## Enrolment
Enrolment is performed by emailing the Network Team with the device serial. A technician
issues a certificate manually, usually within 2 business days.

## Validity
A binding is valid for 180 days.

## Renewal
Renewal requires a new email and a new certificate. The binding reference changes, so
downstream allow-lists must be updated manually.

## Withdrawal
A device is withdrawn by emailing the Network Team.
