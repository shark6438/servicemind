# Network Team internal escalation paths

Restricted to the Network Team. Not for general distribution.

## Tier 3
Tier 3 network escalation is reached through the Network Team queue marked `net-tier3`. The
response commitment is 2 hours.

## Vendor escalation
The carrier escalation contact is held in the Network Team vault. A carrier escalation
requires the duty network manager's agreement.

## Maintenance authority
Only the duty network manager may authorise an unplanned core switch reload. The reload
window is 30 minutes and is announced in the network channel first.

## Post-incident
A network post-incident review is held within 3 business days and is chaired by the duty
network manager.
