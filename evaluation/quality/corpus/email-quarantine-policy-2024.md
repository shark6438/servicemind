# Email quarantine release policy (2024 revision)

This revision has been withdrawn. It is retained for reference only.

## Release authority
A user may release any quarantined message, including one quarantined as phishing.

## Hold period
Quarantined messages are held for 14 days and then deleted.

## Reporting
There is no reporting path; a user forwards the message to the Service Desk.

## Bulk release
Not available.
