# Data classification standard (revision 1)

This revision has been withdrawn. It is retained for reference only.

## Levels
Public, Internal, Secret. A dataset may carry more than one level.

## Handling
Secret data is encrypted at rest. Other levels are not encrypted.

## Labelling
Labelling is optional. An unlabelled document is treated as Public by default.

## Sharing
Secret data is shared inside the tenant.
