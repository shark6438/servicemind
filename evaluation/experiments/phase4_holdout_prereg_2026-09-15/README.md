**勘误（2026-09-16 项目方裁定）——本节初稿对 1b 的描述不正确，以下为准。**

门禁一 1b 是一把**结构性零基线的「挽救率」端点**（`rescue_rate@5`）：困难集定义为
「C0 融合臂 top-10 未命中」，故 C0 在该子集上的 R@5 **按构造恒为 0**，基线不是测出来的
一个数，而是恒等于零。**但零基线并没有把标准抬高**——判据的合格线由数据决定，
而非由基线决定。在 n = 71 上用协议 §6 冻结的配对自助（10,000 次、种子 `20260915`）实测：

| 挽救条数 | `rescue_rate@5` | LCB(0.025) | 1b 判定 |
| ---: | ---: | ---: | :---: |
| 0 | 0.0000 | 0.00000 | ✗ |
| 1 | 0.0141 | **0.00000** | ✗ |
| 2 | 0.0282 | **0.00000** | ✗ |
| 3 | 0.0423 | **0.00000** | ✗ |
| **4** | 0.0563 | **0.01408** | **✓** |
| 5 | 0.0704 | 0.01408 | ✓ |
| 6 | 0.0845 | 0.02817 | ✓ |

**「只要挽救一条就能通过」是错的。** 一条成功样本在「71 抽 71」的自助重采样中被整批
抽漏的概率是 `(1 − 1/71)^71 = 0.3653`，故 1、2、3 次挽救的 2.5% 分位数**都仍然是 0**；
**需要至少 4 次挽救**置信下界才稳定高于 0。**本轮实际挽救数为 0**，因此在任何合理统计
方法下（配对自助、精确二项检验或其他）都拿不到 Top-5 收益证据——
**它不是被刀刃判据误伤，而是确实没有挽救发生。**
这是协议设计错误：错在基线的**命名与解释**（应叫 `rescue_rate@5` 并配有业务意义的最低
挽救率），**不是判据本身有缺陷**。

**第二条独立理由**：门禁一 1a 不依赖上述端点，它在全体 330 条上
Δ = +0.0000、LCB = −0.0091，**独立地未通过**。**即使把 1b 整个删除，收益门禁仍然失败。**

**结论口径（修正后）：第三臂未证明 Top-5 召回收益。** 但在 Recall@10、MRR@10、NDCG@10 上
**通过了预注册非劣门禁**，三项均为正向（+1.52pt / +1.35pt / +1.36pt，LCB 均 > 0），
呈现**排序改善**；该改善**主要发生在第 6–10 位**，不足以支持生产采纳。

开发集上的困难集 Recall@5 **+5.67pt 没有复现**（留出集 71 条中 C1 把 6 条捞进 top-10、
**0 条**进 top-5）。全体 Recall@5 的 +0.0000 不是「毫无变化」：330 条中逐 query 差值
**只有 2 条非零**，恰为 −1.0 与 +1.0 精确抵消。门禁二三项全部通过且 LCB > 0 ⇒
第三臂的收益**主要落在第 6–10 位**，是**重排质量**的改善，不是**召回覆盖**的改善。

## 清单与校验

`manifests/artifacts.sha256.json` 登记 13 个产物。三种来源，**不可混用校验方式**：

| 来源标记 | 是否复制入库 | 校验方式 |
| --- | --- | --- |
| `location: repo` | **否**（已在 git 追踪中，避免双份漂移） | 按仓库相对路径读文件字节哈希 |
| 无 `location`（落在 `evidence/`） | **是**（因 `data/phase4/raw/` 被 `.gitignore` 排除） | 读本目录文件字节哈希 |
| `location: gitignored` | 否 | 仅登记哈希；385MB 嵌入矩阵，可由固定 revision 重新生成 |

`evidence/phase4_holdout_prereg_2026-09-15_rankings.json.gz` 按**解压后**字节哈希
（与 `../phase4_third_arm_2026-09-15/` 的 `pools/` 同一约定）——否则清单哈希会随压缩级别
变化而失效。该文件含 `query_ids / answerable / relevant / c0_pools / c1_pools /
c0_rankings / c1_rankings`，**审计者无需 GPU 即可复算全部指标与配对自助区间**。

```bash
python3 - <<'VERIFY'
import gzip, hashlib, json
from pathlib import Path
arch = Path("evaluation/experiments/phase4_holdout_prereg_2026-09-15")
man = json.loads((arch / "manifests/artifacts.sha256.json").read_text())
bad = 0
for a in man["artifacts"]:
    if a.get("location") == "gitignored":
        continue
    p = Path(a["path"]) if a.get("location") == "repo" else arch / a["path"]
    raw = gzip.decompress(p.read_bytes()) if p.suffix == ".gz" else p.read_bytes()
    ok = hashlib.sha256(raw).hexdigest() == a["sha256"]
    bad += not ok
    print("OK " if ok else "MISMATCH", a["path"])
print("mismatches:", bad)
VERIFY
```
